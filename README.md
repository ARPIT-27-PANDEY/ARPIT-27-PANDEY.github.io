## Deploy

This repository is intended to be served directly through GitHub Pages.

In GitHub:
1. Open **Settings → Pages**.
2. Set **Source** to **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

The personal site URL will be:

https://arpit-27-pandey.github.io/

## Local preview

No build step is required:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
